## 运行

### 使用 Windows 完整交付包

在 [Releases](https://github.com/wayofmusic/h5deck-presenter/releases) 下载 `h5deck-platform-v0.2-windows.zip`（中文说明为“双屏演讲平台-v0.2-完整交付包”），完整解压后双击顶层的“启动双屏演讲.cmd”。完成后运行“停止双屏演讲.cmd”。该包包含 Node 运行时与依赖。

手机与电脑需要处于可互通的局域网。工作台选择课件，打开投屏，再选对应网卡并扫码配对。详细用法见源码目录 README 与 STATUS。

### 从源码启动

使用 Node **24.22.1**；进入源码目录执行：

```powershell
cd "双屏演讲系统-Codex开发交接包"
npm ci
npm run build
npm start
```

终端会输出电脑工作台地址。仓库排除了 `runtime/` 和 `node_modules/`，源码安装方式使用系统 Node；便携包则使用包内运行时。

### 验证

仓库根目录：

```powershell
node scripts/verify-backup.mjs
```

源码目录：

```powershell
npm run check
```

GitHub Actions 在提交与 PR 上检查版本一致性、14 个基线文件哈希、构建与现有 Node 自动化测试。

## 用 AI 制作新课

先读 [一页纸教程](大航海周报-20261105/02-一页纸AI案例教程.md) 与 [完整分步提示词](大航海周报-20261105/双屏演讲-三页练习包/AI制课练习/分步提示词.md)。教程附件采用独立练习包目录；直接复用平台源码时，以源码目录中的 [内容包制作指南](双屏演讲系统-Codex开发交接包/03-标准内容包制作指南.md) 为准。

制作顺序是：资料与目标 → 可讲逐字稿 → 逐页结构与点按表 → 三页呈现 → 试讲修订 → 分段扩展。

当前输出为 H5 内容包；原生 PPTX/PDF 需要适配。完整能力和未验证事项见 [STATUS](双屏演讲系统-Codex开发交接包/STATUS.md)。

## 备份与版本

- 源码、文档、必要素材、`.h5deck` 内容包和匿名练习代码进入 Git。
- 已有 ZIP 交付包及课件库快照作为 `v0.2.0` Release 附件保存，下载后可使用 `SHA256SUMS.txt` 校验。
- Release 使用英文下载文件名以避免中文名被 GitHub 改写；`RELEASE-ASSETS.json` 同时记录原名 `name`、下载名 `release_name` 和原工作区路径。
- `node_modules/`、运行时、构建目录、缓存、临时验证目录、`.runtime/`、本机 `data/` 和凭据不进入 Git。
- 活跃 `data/` 不直接入库；已导入内容单独保存在“课件库快照-20261105”，恢复方式见该目录说明。运行会话和控制凭据不备份。

后续提交、发版和恢复步骤见 [VERSIONING.md](VERSIONING.md)，当前变更见 [CHANGELOG.md](CHANGELOG.md)。
