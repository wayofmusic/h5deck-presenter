# Codex 开发接续说明

当前 v0.2。先读 [顶层文档](00-顶层开发文档.md)、[STATUS](STATUS.md)、[制作指南](03-标准内容包制作指南.md)。

用户已授权平台化，包导入/课件库、SDK/沙箱、两套模板与 init/validate/pack 已实现。新增课程优先制作内容包，不复制应用或修改内核。内置 AI、安装器、眼镜、长课程、原生 PPT 仍在假设池。

下一步优先验证 v0.2 真机导入课程、后台恢复与稳定性。两部 Android 手机反馈仅属于 v0.1；没有设备时继续独立工作，并保留缺口。

使用 runtime/node.exe，命令见 README，不重复初始化。修改新内容先 validate 再运行。release 工具生成一个 ZIP，验证解压产物。

持续约束：

- 保留 baseline 的 32 页、讲稿、肖像、二维码与视觉，14 个源文件有哈希对照。
- 页 ID、展开步骤、备注对应；分步/直接翻页分开；手机滚动不翻页。
- 服务统一状态；快照不再发命令；断线不积压；电脑显式恢复。
- 单主控、可撤销；讲稿独立；内容 iframe 不获取私有凭据。
- 保持无 baseline 启动，互动由清单声明，不在内核写课程专用白名单。
- 不自动上传私人资料，不由本地开发推导公网发布授权。
- 设备、网络、时长、容量与干净环境分别留证，移动视口不冒充真机。

完成后更新 STATUS 与实际内容标准，说明入口、验证与缺口。用户最新指令更新范围，不重复索要已给出的授权。
