# 柴翔｜Y 模型与 AI 长期竞争力

这是一套覆盖整场约 60 分钟分享的 32 页、16:9 演讲型网页 PPT。最后一页包含柴翔形象照、简短介绍与微信二维码。

## 打开

解压后，用 Chrome 或 Edge 双击打开“柴翔-Y模型与AI长期竞争力-演讲版.html”。HTML 单文件已包含全部内容与图片，不需要联网、安装或启动服务。

## 演讲

- 空格、右方向键：渐进展开，再翻页。左方向键返回。
- Shift + 右方向键：直接下一页。Home / End：首页 / 尾页。
- O：目录；N：打开或收起演讲提示；F：全屏；T：开始或暂停计时。
- R：重播本页；B：黑屏，点击或任意键恢复；?：查看帮助。
- 控制栏会在静止约 4.5 秒后淡出，移动鼠标或按键即可出现。
- 备注区包含逐页讲稿、现场节奏、计划时间与下一页提示；显示在同一窗口，投屏时按 N 收起。
- 移动端支持滑动与底部大按钮，推荐横屏。

## 互动

第 9、25、30 页为可点击的 Y 模型，第 30 页带五分钟练习计时。点击五个 Step 或理论、事实、认知等节点填写。可以切换“模型讲解 / 企业培训案例 / 我的 90 天”三张独立画布。

画布可保存在当前浏览器，支持导出 Markdown 文字版、JSON 备份与重新导入。不同浏览器、移动文件位置、隐私模式可能影响本地保存，请填写后导出备份。点击清空前会再次确认。

## 内容依据

- Y 模型：用户提供的 Y模型(2).pptx，2 页，原始宽高比约 8:3，已直接导出并逐页检查。网页已移除原稿入口及原始 PPT 图片。
- 完整保留 Step1:范围、Step2:目标、Step3:框架、Step4:预判、Step5:配套；理论与事实和我的认知的双向关系；知行合一的因果规律；解决真正问题。
- 使用现成模型/规律、自己建模型、提出新假设、定性定量均保留。讲稿中关于科学类比、假设驱动、提炼模型与持续迭代的说明放入备注，未替换原模型标签。
- 个人经历、2011 / 2014 / 2020以后 / 2024以后路线，以及企业培训案例来自本次提供的讲稿。没有虚构企业名称、客户数量、收入或效率成果。
- 三个月减少三成只是待验证目标示例；“多、好、快”和个人能力系统为讲稿中的个人理解；真实流程转换自动化仍保留“当时尚未稳定”的边界。
