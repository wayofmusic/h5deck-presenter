# H5Deck｜随身讲台：产品包装与商业模式

2026-11-05 · 基于双屏演讲平台 v0.2 与当前项目材料

**建议先做“讲师的双屏开讲服务”：把一套内容，交付成观众看得清、讲者有稿可看、现场能够排练使用的演讲方案。** 首阶段用服务收费验证需求，软件承担交付与复用；形成重复购买以后，再决定订阅与授权。

本文件中的名称为品牌建议，未核验商标；人群、价格、成本与转化目标均为待验证方案，未声称已有付费客户、成交记录或市场统计。

## 1. 给用户的一句话

**H5Deck 随身讲台，让逐页讲稿跟着课件走。**

观众看大屏，你看下一句。电脑展示课件，手机显示当前页讲稿，还能控制翻页和内容展开。从课件适配、讲稿配页到双屏排练，帮你把下一场课或演讲准备到可用。

对外品类：双屏授课与演讲服务。首次解释可说“手机看稿和控场的演讲方案”，随后再介绍 H5 形式。

主张语：**把准备留在幕后，把表达留在现场。**

## 2. 谁会买，在哪个时刻买

以下为基于项目能力的需求假设，尚无访谈或付费数据证明排序。

| 优先级 / 人群 | 具体购买时刻 | 现在的痛点 | 实际交付的价值 | 谁付费 |
|---|---|---|---|---|
| 第一：独立讲师、咨询顾问、知识型创作者 | 一到两周内要开付费课；首次讲新课；已有课程开始巡讲 | 内容熟悉但新稿难记，讲义和画面分开找；既要讲又要操作 | 把一套课程做成逐页对应的双屏演示包，完成手机联调与排练，可带到后续场次复用 | 讲师本人或其工作室 |
| 第二：企业内训师、培训项目负责人 | 新员工培训、产品培训、销售训练营将开课 | 同一课反复讲；新人讲师容易漏点；课件与讲稿交接费力 | 一套品牌课件配一套逐页讲稿，明确讲授顺序与展开节奏，提供讲师使用说明 | 培训部门 / 项目预算负责人 |
| 第二：创始人、管理者、活动发言人 | 发布会、年会致辞、主题演讲临近 | 重要数字和措辞不敢漏，台上不方便返回电脑找稿 | 已定稿内容配页、关键画面制作、手机稿及排练；复杂场地另行评估 | 发言人团队 / 活动负责人 |
| 第三：培训机构、课研公司 | 多名讲师开始交付同一课程 | 资料分散、讲法不一致、课稿交接缺说明 | 以一个真实模块试点，形成可重复制作和交接的标准包 | 课程负责人 / 机构老板 |

首批画像建议：有近期明确场次、有已定稿材料、愿意用自己的 Windows 电脑、可以提前排练，且愿意为内容与交付付费的人。采购只求最低价遥控工具、必须原生 PPT 全效果无损保留的人，匹配度较低。

## 3. 功能如何转成用户利益

| 已有能力 | 用户能感知的利益 | 可用于广告的表达 |
|---|---|---|
| 手机逐页讲稿跟随电脑页码 | 翻到哪页，手边就有哪页的内容 | 让逐页讲稿，跟着课件走 |
| 手机翻页与点按展开，电脑操作也同步 | 讲述、看稿和操作围绕同一进度 | 一部手机，讲稿与翻页都在手边 |
| 大屏画面与私有备注分开提供 | 观众看精简画面，讲者保留完整表达 | 观众看大屏，你看下一句 |
| 内容库及可替换内容包 | 已完成的课可以保存、换课并继续使用 | 把你的拿手好课，带到下一场 |
| 计时、跳页、黑屏及电脑接管 | 排练和现场操作有明确入口 | 从讲稿配页，到双屏排练 |

“更从容”“少分心”是设计目标与体验主张；不能扩大成保证不紧张、不忘词、不出错。

## 4. 广告产品怎么卖

### 主推商品：一套课，双屏开讲

建议商品名：**H5Deck 双屏开讲包**。

销售页面开头可以直接使用：

> 你负责把内容讲明白，我们把大屏、讲稿和翻页接起来。
>
> 带上你已经定稿的课程或演讲材料，我们先确认适配方式，再做成观众屏与讲者屏对应的演示包。你用手机看当前页讲稿、控制翻页和展开，并在正式使用前完成一次双屏排练。

最小交付清单：

1. 确认过的页序与讲稿映射表。
2. 约定页数内的 H5 课件及逐页讲稿内容包。
3. Windows 便携演示环境、启动说明与个人内容备份说明。
4. 一次客户指定电脑、手机和网络条件下的远程联调与排练。
5. 约定周期内、约定次数的内容修订及使用支持。

输入为已定稿材料时保留正文；需要提炼、重写、补稿或原创视觉时单独报价。现有 PPT/PDF 先抽查三页，区分静态承载、重点页重建与不适合迁移的内容，再确认范围和报价。

**建议验收口径：** 在双方约定设备和网络中，逐页核对画面与讲稿；验证翻页、展开、回退；完成一次约定时长的连续演练；客户能按说明重新打开。后续换设备、换网络需重新排练。现场服务按验收后的支持范围报价。

## 5. 推荐的商业模式与价格实验

以下是人民币试售测试价，不是竞品报价、现行售价或收入预测。税费、授权主体、修订范围与服务时间应在正式报价时说明。

| 阶段 / 商品 | 建议测试价 | 可检验的范围 | 收费逻辑 |
|---|---:|---|---|
| 首批付费体验包 | ¥999 / 套 | 不超过12页；客户提供定稿正文与可用素材；一个现成主题；一次修订；一次30分钟远程联调 | 降低首次尝试门槛，同时验证真实付费，避免无边界免费定制 |
| 主推双屏开讲包 | ¥2,980 / 套 | 不超过30页；已有内容适配；逐页配稿；一个主题；两次集中修订；一次45分钟远程排练 | 主要利润来自内容整理、适配和可使用的交付 |
| 重要演讲定制包 | ¥6,800 起 / 场 | 不超过30页；约定范围的表达打磨及关键视觉；两次远程排练；最终交付时点明确 | 为更高要求的内容与排练投入收费，先核算工作量 |
| 机构课程维护包 | ¥12,800 起 / 季 | 最多3个短模块、合计不超过90页；约定主题、更新轮次和远程支持小时；先以一个模块验收 | 用明确产能换持续收入，采用里程碑交付 |
| 后期个人软件授权实验 | ¥399 / 年，待自助体验验证后测试 | 支持的设备与版本、更新与支持边界写清；内容制作另计 | 只有用户能独立安装、导入、复用并需要持续更新，年费才有依据 |

这些是候选套餐，实际成交先做材料评估。页数只是范围控制，复杂互动、原创图表、长视频、加急、现场到场与新增章节另算；不对“几百页任意课件”采用统一单页低价。

建议现在只上架体验包和主推包。高价定制用需求评估报价；机构季度包在客户实际复用后销售；个人授权留作后续实验，不把未实现的编辑、AI或团队协作当成订阅权益。

### 哪些收入应优先

**先做：** 标准适配制作费、重要演讲项目费、老客户改稿与新课程费。

**随后做：** 有明确工时上限的机构维护、讲师上手培训、合作伙伴转介。

**具备条件再做：** 个人授权与软件更新服务、可复用模板和内容包；云端协作或AI若要收费，先实现并验证，不作为当前承诺。

合作对象建议从培训机构、课件设计师与活动服务商中找，先约定一个联合交付项目。分成比例根据真实毛利协商，不先承诺全国代理、独家区域或无限售后。

## 6. 一单是否赚钱：先把自己的时间算进去

以 ¥2,980 主推包为例，以下全部是用于决策的假设，并非实际成本：

| 成本项 | 假设 | 金额 |
|---|---|---:|
| 梳理、适配、配稿、校对与修订 | 合计12小时 × ¥120内部工时 | ¥1,440 |
| 获客与售前沟通分摊 | 每成交一单 | ¥300 |
| 图像 / 素材 / 工具分摊 | 按实际授权与消耗核算 | ¥120 |
| 后续使用支持 | 2小时 × ¥120 | ¥240 |
| 合计 |  | ¥2,100 |
| 交付贡献额 | ¥2,980 − ¥2,100 | ¥880，约29.5% |

这是计入假设人工与获客后的单笔贡献，尚未扣税费、退款、差旅及固定管理支出，不能称为净利润。如果制作从12小时升到20小时，总成本变为 ¥3,060，单笔贡献为 −¥80。**商业模式的关键是复用模板、收紧范围、控制返工和售后工时。**

因此先记录五单真实工时，再决定涨价、缩小交付或保留哪些互动类型。重复课程更新比每次从零重做更值得培养，但不能预设所有客户都会续费。

## 7. 为什么用户会选你

手机遥控与演讲备注已有替代方案：Apple Keynote Remote 提供遥控及演讲备注布局；reveal.js 提供逐页备注、下一页预览和计时。因此，“手机看稿”本身不足以支撑独家技术溢价。[Apple 官方说明](https://support.apple.com/en-ae/guide/keynote/tan85f5c958c/mac) · [reveal.js 官方说明](https://revealjs.com/speaker-view/)

Logitech Spotlight 等演示器也提供演示控制和指向功能，不能把本项目宣传成唯一能让讲者离开电脑的方案。[Logitech 官方产品页](https://www.logitech.com/zh-cn/shop/p/spotlight-presentation-remote)

由上述资料与项目现状推断，值得测试的差异是：**针对 Windows 本地 H5 课程，把内容适配、讲稿配页、互动节奏、双屏排练和交接复用一起交付。**

真正能积累的资产是课程主题、适配组件、校验与交付流程、真实设备兼容记录、客户的复用课程和服务口碑。AI 可用于制作环节，但当前平台未内置 AI，不能作为现成功能销售。

## 8. 首月怎么找到第一批付费用户

不建议起步就投大额广告。先从已有讲师、顾问、培训与活动人脉中接触有近期场次的人；下列为候选实验目标，不是转化承诺。

| 时间 | 建议负责人 | 行动 | 预期得到的证据 |
|---|---|---|---|
| 第1周 | 项目负责人 | 录一条30秒真实双屏视频；在自己的渠道展示海报；与10位有近期场次的人交流 | 哪个场景最有吸引力，谁愿意拿出自己的材料 |
| 第2周 | 项目负责人 | 为合适对象做10分钟演示；售前只抽查三页；争取3个付费体验订单 | 用户是否为明确范围付款；不把口头兴趣当需求成立 |
| 第3周 | 制作与交付负责人 | 交付并记录制作、修订、联调、售后时间；按实际设备排练 | 有无错页、启动障碍；单笔贡献是否为正 |
| 第4周 | 项目负责人 | 访谈真实使用者；询问下一套课或下一场是否需要继续用 | 复用原因、可接受价格、主动转介意愿；获许可后才公开案例 |

漏斗应记录：看到演示的人 → 有近期场次的有效咨询 → 完成材料评估 → 付费 → 按范围验收 → 真实场次使用 → 第二次订单。海报点赞只用于比较创意，不视为产品验证。

三个放大门槛建议：至少3单在计入人工与获客后仍为正贡献；至少两次真实场次使用通过且无课稿错页等阻断问题；至少两位客户愿意带第二套内容付费回来。这些是内部候选门槛，应随样本调整。

## 9. 演示与成交怎么说

30秒演示脚本：

> 开头5秒：镜头同时拍到电脑课件和手机。“你有没有遇到：翻到下一页，忘了这一页本来要说什么？”
>
> 中间15秒：手机点击下一步，大屏内容展开；再用电脑翻页，手机讲稿跟随。“大屏给观众看重点，手机给你看当前页讲稿。翻页和展开，也能在手机上完成。”
>
> 最后10秒：“我把它做成了 H5Deck 双屏开讲服务，从课件适配、逐页配稿到双屏排练。你有近期要讲的一场课，可以私信‘开讲’，先看一次演示。”

常见异议：

| 用户问 | 回答建议 |
|---|---|
| 我已经有翻页笔了，为什么还需要？ | 如果你只需要翻页，现有工具可能已经够用。这个服务适合还需要逐页讲稿、H5内容适配和开讲排练的人，先看双屏演示再判断。 |
| 直接把我原来的PPT放进去就可以？ | 我们先抽查材料。当前系统面向已适配H5；你的动画、视频和字体是否需要重建，要在确认范围后报价。 |
| 扫码以后一定能连上吗？ | 需要手机和电脑所在网络互通。我们会在约定设备上先联调，会场若隔离设备，需要另选可行网络并排练。 |
| 你能帮我写稿吗？ | 可以把稿件整理或重写作为单独服务约定；已有定稿默认保留原文，缺稿不按已经有稿处理。 |
| 我买的是不是以后所有课都免费做？ | 每套内容按约定范围交付；后续新课、改稿和支持另行约定，已验收的课件包可按约定复用。 |

## 10. 广告与交付边界

可以宣传：当前页手机讲稿、扫码配对、双向控制、点按展开、Windows本地H5演示、内容包复用，以及明确由人工提供的制作和排练服务。

不得当作已实现卖点：任意PPT/PDF无损一键转换、内置AI一键制课、语音自动跟稿、多人云协作、智能眼镜、永久不掉线、所有设备通用或长时间零故障。

项目已有 v0.1 两部安卓手机反馈；v0.2 新内容包流程、热点、长时间与干净 Windows 等仍有验收缺口。早期适合受控试点；每个客户按实际设备与网络验证，不把旧版反馈扩展为新版全兼容。

海报为广告概念场景及界面示意，不是客户实拍或真实案例。未使用项目中的私人肖像与微信二维码；统一采用私信关键词作为引导。公开发布前确认品牌名、账号承接路径与最终服务范围。
