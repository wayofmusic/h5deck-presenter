# 从资料到课件：从这里开始

## 先让 AI 做好内容
1. 在 WorkBuddy 等本地编程助手中选择整个练习包作为工作目录。
2. 打开 AI制课练习/制作要求.md，可先保留示例，再换成自己的听众、任务、时长与资料。
3. 按 AI制课练习/分步提示词.md 一段一段发送。读资料 → 写可讲稿 → 拆页面与点按 → 做三页画面 → 试讲修订。
4. 逐页设计表示例.md 用来对照交付。先确认讲稿和点按表，再让 AI 实现 H5。
5. 最后应有 产出/讲师稿.md、产出/逐页设计表.md、app/my-course 源目录和 app/my-course.h5deck。

## 再用双屏检查讲述效果
1. 这是 Windows 64 位便携包，运行演示无须另装 Node，也不依赖智能体在线。先完整解压，不在压缩软件内部运行。
2. 双击“启动双屏演讲.cmd”。电脑工作台显示“本地服务已连接”。没自动打开时，在 app/.runtime/server.log 查看电脑设置地址。
3. 点“导入内容包”，选 app/my-course.h5deck。导入后在“当前课件”选新课，再点“打开投屏画面”。没有制作自己的课时，可先用“三页复用验证”检查连接。
4. 手机与电脑连接可互通的 Wi-Fi。工作台选择对应 Wi-Fi 网卡，“重新配对”，手机扫码后用浏览器打开。配对码两分钟有效且只用一次。
5. 大屏看当前画面，手机看对应稿。按设计表讲到哪句点哪下，先连着讲完三页，再看哪里需要改。不要用软件能打开代替内容质量检查。
6. 用完双击“停止双屏演讲.cmd”。只关网页不会停止后台服务。

## 常见卡点
- 扫码打不开：电脑工作台应先显示已连接；选实际 Wi-Fi 网卡，避开 VPN/虚拟网卡。手机不能用 localhost 访问电脑。微信内打不开可复制到手机浏览器；某些网络会隔离设备，需换可互通网络。
- 配对码失效：电脑点“重新配对”，再扫码，不用旧截图。
- 导入后仍是旧课：在“当前课件”下拉框切换。导入不自动切课，切课后手机要重新配对。
- 提示重复版本：让 AI 把 app/my-course/manifest.json 与 private/notes.json 的 revision 一起加一，再校验和打包。
- 画面是提纲、手机稿也只有提纲：返回第二段提示词，先补齐可直接说的正文，再更新备注映射。
- 动画抢答：在逐页设计表写出答案出现的触发句，再要求 AI 绑定对应点击；等待期间不自动播放。
- 短暂断网：已加载的电脑投屏可继续讲；手机恢复后先等最新状态，不积压点击。服务重启而投屏还在时，可在投屏按 C 恢复遥控；恢复前不要刷新。

## 保留什么
产出 中的稿件与设计表、app/my-course 源目录、app/my-course.h5deck 内容包、app/data 导入库。
runtime/LICENSE.txt 和 node_modules 内许可证随包保留。公开仓库前排除私人材料、app/data、app/.runtime、日志与会话凭据。
本包输出 H5 演示，任意 PPTX/PDF 无损转换和原生 PPTX 导出不在本版实现范围。运行验证条件见“本次验证说明.md”。
