# 标准内容包制作指南｜v1

当前平台版本：v0.2。内容格式：`h5-presenter-content/1`，桥接协议：`h5-presenter-bridge/1`。

本指南对应已经实现的格式、SDK、导入与制作工具。原 [02-平台与内容包标准草案](02-平台与内容包标准草案.md) 保留为设计过程，不是接口源文件；机器校验以 `standards/` 中的 Schema 为准。

## 1. 普通使用：同一平台添加新课程

1. 电脑启动平台，在工作台点击“导入内容包”。
2. 选择 `.h5deck` 或符合格式的 ZIP，平台检查后存入本地课件库。
3. 在“当前课件”下拉框选择刚导入的课程，打开投屏窗口。
4. 切课会建立新会话并撤销旧手机控制；用新二维码重新配对。
5. 同一套手机界面提供该课程的逐字稿、步骤、跳转、计时和恢复。

导入不会立即切走当前演讲，失败也不替换当前课程。同一 deckId/revision 不覆盖；修改课件版本后可以作为另一版本导入。

完整交付包内的“示例内容包”含基础与互动两个样例，工作台也能直接下载。

## 2. 开发者：从模板开始

以下命令在项目根目录执行；完整交付包对应 `app` 目录。目标目录须不存在，工具不会覆盖已有制作内容。

```powershell
.\runtime\node.exe packaging/content-cli.mjs init "D:\我的课程\沟通课" basic
.\runtime\node.exe packaging/content-cli.mjs validate "D:\我的课程\沟通课"
.\runtime\node.exe packaging/content-cli.mjs pack "D:\我的课程\沟通课" "D:\我的课程\沟通课.h5deck"
```

用 `interactive` 替代 `basic` 可取得带互动选择与状态恢复的模板。更换 `deckId` 与 `revision` 时，manifest 和 notes 中的标识必须一起更新。

创建后修改：

- `manifest.json`：课程身份、公开资料、页面 ID、顺序、展开数量、能力和互动状态声明。
- `private/notes.json`：逐页讲稿、段落与现场提示。
- `presentation/index.html`、`style.css`：画面与样式。
- `presentation/adapter.js`：这套 HTML 如何应用平台状态、如何提交互动意图。

## 3. 文件结构与资源

```text
manifest.json
private/notes.json
presentation/index.html
presentation/style.css
presentation/adapter.js
assets/                      可选，本地图片、字体或媒体
```

包根目录必须直接有 manifest，不要再多套一层文件夹。v1 支持包内相对资源以及平台 SDK 地址 `/sdk/presenter-sdk.js`。静态 HTML/CSS 的资源引用会检查存在性与公开/私有边界；动态脚本生成的引用还须实际运行检查。

v1 内容默认不访问外部网络或平台私有接口。API 联网、任意外部网页、嵌套 iframe 等不在当前内容能力中。音视频文件可作为资源打包，但大型媒体和播放/拖动兼容尚未专项验收。

## 4. 格式规则

清单必须满足 [manifest.schema.json](standards/manifest.schema.json)，讲稿满足 [notes.schema.json](standards/notes.schema.json)。两套实际可复制样例在 `content-templates/`。

- `packageFormat` 固定为 `h5-presenter-content/1`，`schemaVersion` 为 1。
- `adapter.protocol` 固定为 `h5-presenter-bridge/1`，entry 指向 HTML，adapter.path 指向包内 JS。
- 页面 ID 唯一；备注 `slides` 的 key 与页面 ID 对应，段落 ID 唯一。
- `steps` 是可见状态数量：进入页面为 1，当前页最后一步之后才进入下一页。
- 未启用 reveal 时每页 steps 必须为 1。备注、清单、修订和课件身份要匹配。
- 若声明互动状态，启用 `widgetSnapshot` 并在 widgets 声明对应 key、类型、初始值与范围。
- 当前可同步互动值为整数、数值、布尔或字符串，支持 enum、min/max 和 maxLength；复杂对象、多人互动和自定义服务器插件未实现。

导入防护限制为压缩包 64 MiB、解压合计 200 MiB、单文件 25 MiB、最多 2048 项。Schema 的页面数量检查上限不代表几百/几千页性能已经验证。

## 5. SDK 接入

在内容入口加载平台提供的经典脚本，再加载本包适配器：

```html
<script src="/sdk/presenter-sdk.js"></script>
<script src="adapter.js"></script>
```

适配器的最小结构：

```javascript
PresenterContent.register({
  getSlides: () => [
    { id: 'opening', steps: 1 },
    { id: 'practice', steps: 2 }
  ],
  applySnapshot(state) {
    // 按 state.slideId、state.revealStep、state.publicWidgetState 展示内容。
    // 不在这里再次发送翻页命令。
  },
  destroy() {
    // 可选：清理本内容建立的监听、动画或计时器。
  }
});
```

`getSlides` 返回完整顺序与步骤，须与清单一致。`applySnapshot` 可以异步，完成后 SDK 会确认版本；抛出异常或不确认时投屏页明确显示错误。

内容按钮通过 `PresenterContent.request(action, params)` 提交意图，例如：

```javascript
PresenterContent.request('NEXT_STEP');
PresenterContent.request('GOTO_SLIDE', { slideId: 'practice' });
PresenterContent.request('WIDGET_ACTION', { key: 'choice', value: 'practice' });
```

SDK 支持分步、直接翻页、指定页、重播、黑屏、演讲/练习计时和已声明互动动作。导航键、B/T/R/F/C 也由 SDK 转交平台；输入框和已处理的键盘事件不被抢占。

`PresenterContent.getSnapshot()` 返回最近应用的公开快照。内容端不获得手机讲稿、本机控制凭据或任意本地文件能力。

注意将“展开片段”的 DOM 选择器限定在实际页面里。模板曾因泛选 `[data-step]` 误选 body 上的状态标记而隐藏整页，已修复；修改模板后应检查前进、回退与重载。

## 6. 内容隔离与运行检查

内容运行在只允许脚本的 sandbox iframe 中，桥接绑定具体 frame、协议和实例标记。父平台应用服务端确认的快照，H5 不独立抢占全局页码。

公开资源路由不提供 manifest 原文件、private 目录或讲稿路径；手机凭演讲者权限读取 notes。把讲稿文字直接写进公开 HTML/JS 仍会公开它，制作者必须保持分离。

内容可以实现自己的本地互动。只有通过已声明 widget 状态提交的结果保证在当前会话刷新和显式恢复时可还原；临时 DOM 变量不自动同步。

校验工具检查结构、标识、静态引用和资源边界。它不能代替视觉、交互和事实核验，也不会把未适配 HTML 自动转换成可控幻灯片。

## 7. 给外部 AI 的制作指令

```text
按 H5 演讲平台内容格式 v1 制作标准包源目录。
先读取平台的 manifest/notes Schema 和 basic 或 interactive 模板。
保留平台 SDK 注册与命令路径，getSlides 与清单顺序和步骤一致。
每页有唯一 ID，屏幕呈现要点，完整讲稿只写入 private/notes.json。
页面、段落、课程身份与 revision 一一对应，素材全部位于包内。
采用当前 SDK 支持的互动值类型与字段，不自行假设平台提供外网 API 或服务器插件。
保留原材料事实边界，缺素材/数据时标记待补，不虚构结果或引用不存在的文件。
先完成结构校验，再实际检查展开、回退、页面内按钮、互动恢复与手机稿件对应，最后用 pack 命令生成 .h5deck。
```

平台目前提供模板与标准制作工具，尚未内置大模型生成、可视化编辑器或任意 PPTX 自动转换。

## 8. 数据与升级

源码运行时，默认数据在项目 `data/`；可用 `PRESENTER_DATA_DIR` 指定其他位置。完整交付包的顶层启动入口使用同级 `data/`，与程序 `app/` 分开。

备份整个 data 目录可保留导入内容与最后选择。升级时保留 data，不复制旧 `.runtime` 会话目录。内容版本保持独立，当前没有自动合并、跨版本阅读位置迁移或内容删除 UI。

服务重启后内容库和最后选择仍在，页内演示进度由已打开的电脑窗口按 C 显式恢复；所有窗口和服务都退出后的跨天断点不在本版承诺内。
