## 01 讲师开新课

课件翻到哪页，讲稿就到哪页。

独立讲师 / 咨询顾问 / 企业内训师

手机看当前页讲稿，翻页与展开也在手边。

四个利益：逐页配稿·讲到哪里，看哪里；双向同步·电脑翻页，手机跟随；手机控场·翻页、回退、点按展开；阅读可调·字号与滚动独立设置。

服务：课件适配 → 逐页配稿 → 双屏排练。

行动：私信「演示」，看一次真实双屏操作。

## 02 产品解释

大屏给观众，讲稿留手边。

授课 / 路演 / 主题分享

把画面、讲稿和翻页，接到同一场表达里。

四个利益：手机扫码·配对后进入讲者端；逐页讲稿·跟随当前课件页面；点按展开·按你的讲述节奏推进；讲稿分离·观众屏呈现精简内容。

服务：评估材料 → 确认适配 → 联调排练。

行动：私信「演示」，带上你下一场要讲的内容。

## 03 重要演讲

重要的每一句，都值得备好稿。

发布会 / 年会致辞 / 主题演讲

画面呈现重点，手机保留确认的逐页表达。

四个利益：定稿配页·按确认正文拆分讲稿；重点呈现·让大屏承担视觉重点；逐页可看·关键数字与措辞在手边；开讲前练·在约定设备上联调排练。

服务：确认定稿 → 画面配页 → 双屏排练。

行动：私信「演示」，预约你的演讲适配方案。

## 04 课程复用

一套拿手好课，准备好下一场。

讲师巡讲 / 企业内训 / 课程交付

课件、逐页稿与使用说明，成套交付与复用。

四个利益：成套保存·一门课配一套内容包；课稿对应·逐页整理，方便复习；换课使用·在内容库选择课程；上手排练·交接前走一遍双屏流程。

服务：梳理内容 → 制作课稿 → 排练交付。

行动：私信「演示」，先评估一段真实课程。
