# 已导入课件库快照｜2026-11-05

本目录保存当前源码运行环境中已导入的 17 套课程，包括完整 12 单元课程、技术地图两个修订、试讲片段、调试实操及正式发言。

## 在新环境恢复

1. 先停止双屏演讲服务；若目标已有自己的课程库，先另存一份。
2. 源码运行：将本目录的 `content-library` 和 `settings.json` 复制到“ 双屏演讲系统-Codex开发交接包/data/ ”。
3. 完整便携版：复制到解压后与顶层启动脚本同级的 `data/`，不是 `app/data/`。
4. 启动软件，在“当前课件”中选择课程；手机重新扫码配对。

同名的 Release ZIP 将这些内容放在 `data/` 下。此快照保留制作时的内容，不等于每套课程均已完成真实设备与现场授课验收。
